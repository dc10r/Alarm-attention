BGP Commands

Initialize the BGP process with the global
router bgp as-number

BGP process

disables the automatic activation standard IPv4 Unicast
no bgp default ip4-unicast disables the automatic activation

configuring BGP RID
bgp router-id router-id

Configure BGP neighbor’s IP address and autonomous system number
neighbor ip-address remote-as as-number

Specify the interface for BGP session for a neighbor
neighbor ip-address updatesource interface-id

To enable BGP authentication
neighbor ip-address password password

The BGP timers can be modified
neighbor ip-address timers keepalive holdtime [minimum-holdtime]

Initialize the address family
address-family afi safi

Activate the address family for the BGP neighbor
neighbor ip-address activate

BGP neighbor session state, timers, and other
show bgp afi safi neighbors ip-address

Statically set the source address to an interface’s primary IP address
neighbor ip-address update-source interface-id command.

modifies the next-hop address in the NLRI for external BGP prefixes
neighbor ip-address next-hop-self [all]

BGP route reflection
neighbor ip-address route-reflector-client

view

shows an established BGP session
show tcp brief

A BGP session is verified
show bgp afi safi summary

Earlier commands
show ip bgp summary

displays the contents of the BGP database
show bgp afi safi

Displays the contents of the Adj-RIB-Out table for a neighbor
bgp afi safi neighbors ip-address advertised-routes

verify the exchange of NLRI routes between nodes
show bgp ipv4 unicast summary

BGP routes in the global IP routing table (RIB)
show ip route bgp
