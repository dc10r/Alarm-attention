Setting an interface priority
ip ospf priority <0-255>

sets an interface as an OSPF broadcast network type
ip ospf network broadcast

sets an interface as an OSPF nonbroadcast network type.
ip ospf network non-broadcast

Neighbors are statically defined
neighbor ip-address

Set The OSPF network type point-to-multipoint
ip ospf network point-to-multipoint

The OSPF hello timer is modified with
ip ospf hello-interval 1-65,535.

change the OSPF dead interval
ip ospf dead-interval 1-65,535

sets plaintext authentication only on that interface.
ip ospf authentication

plaintext password is configured
ip ospf authentication-key password

sets MD5 authentication for that interface
ip ospf authentication message-digest

sets the MD5 password.
ip ospf message-digest-key key-number md5 password

OSPF cost set manually
ip ospf cost 1-65535 under the interface.
